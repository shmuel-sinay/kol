# קול

שידור הקול של מחשב מרוחק לאוזניות, דרך הדפדפן בלבד.

- `/send` – פותחים במחשב המרוחק (Chrome/Edge על Windows), משתפים מסך עם "אודיו מערכת".
- `/listen` – פותחים אצלך עם האוזניות.

השרת (`server.js`) רק מעביר את השמע בין השניים. קוד הגישה נקבע במשתנה הסביבה `ACCESS_KEY`.

הרצה מקומית:

```bash
npm install && ACCESS_KEY=1234 npm start
```
